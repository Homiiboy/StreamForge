# StreamForge – Quellcode

Dieser Ordner ist für die Quelldateien der **StreamForge Browser Extension v1.6.5** vorgesehen.

Entpacke die ZIP-Datei und lade **den Inhalt der ZIP** hier hoch (nicht die ZIP allein). Die `manifest.json` muss unmittelbar in diesem Ordner liegen, ebenso die referenzierten JS-, HTML- und CSS-Dateien sowie die entsprechenden Unterordner (z. B. `icons/` und `tests/`).

Zur Installation in Chrome öffne `chrome://extensions`, aktiviere den Entwicklermodus und wähle **Entpackte Erweiterung laden**. Wähle dann den lokalen Ordner `StreamForge`, der die `manifest.json` enthält.

**Hinweis:** Die Browser-Erweiterung ist erst vollständig, wenn alle Quelldateien hochgeladen wurden.
