Sichere Installation, Sicherung und Wiederherstellung

Updates werden auf dem ZimaOS-Host ausgeführt, nicht über die Weboberfläche. ForgeCore sichert zuerst das komplette Datenvolume und kontrolliert nach einem Update den Container-Healthcheck.

cd ForgeCore
bash manage.sh doctor
bash manage.sh backup
bash manage.sh update
# Bei Bedarf: bash manage.sh rollback backups/backup-...

Rollback stellt das vorherige Datenvolume einschließlich Einstellungen und Datenbank wieder her. Backups enthalten auch sensible API-Schlüssel und dürfen nicht öffentlich gespeichert werden. Jellyfin-Mediendateien werden dabei nicht gelöscht oder zurückgesetzt.
